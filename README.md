# Employee HR Analytics using SQL

## Project Overview

This project focuses on **Employee HR Analytics using SQL** to analyze employee performance, salary trends, attendance, and attrition data. The goal of this project is to gain business insights from HR data using SQL queries and analytical techniques.

The project demonstrates SQL skills including **Joins, Aggregate Functions, Group By, Subqueries, Window Functions, Ranking Functions, and Data Analysis**.

---

## Objectives

* Analyze employee salary trends
* Identify top-performing employees
* Track employee attendance
* Analyze employee attrition
* Perform department-wise HR analysis
* Generate business insights using SQL

---

## Dataset Information

The project contains **4 tables**:

### 1. Employees Table

Contains employee information such as:

* Employee ID
* Employee Name
* Age
* Gender
* Salary
* Hire Date
* City
* Performance Rating

### 2. Departments Table

Contains:

* Department ID
* Department Name
* Manager Name

### 3. Attendance Table

Contains employee attendance records:

* Present
* Absent

### 4. Attrition Table

Contains employee attrition details:

* Attrition Status
* Reason for Leaving
